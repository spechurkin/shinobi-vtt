# Шиноби для Foundry VTT

Система для Foundry VTT 14 по игре «Шиноби». Она содержит интерактивный лист персонажа, лист транспорта, броски основных
механик, каталог предметов и навыков, таблицы генераторов и инструменты ведущего.

Установка: скопируйте папку `shinobi-vtt` в каталог `Data/systems` Foundry VTT и включите систему при создании мира.
Система рассчитана на Foundry VTT 14.367 и новее в пределах ветки 14.

На листе персонажа доступны три страницы: «Персонаж», «Снаряжение» и «Сеть». Записи можно добавлять из встроенного
каталога кнопкой `+` или перетаскиванием. Кнопки проверок, урона, перезарядки, лечения и киберпространства отправляют
броски в чат и обновляют данные документа.

В поставку не входят полный текст книги, главы, PDF-файлы или журнал с перепечатанными правилами. В каталогах находятся
только игровые данные, необходимые для работы листа и генераторов, с краткими ссылками на страницы источника.

## Разработка

```text
npm install
npm test
npm run check
```

Скрипты в `tools/` извлекают исходные данные и собирают compendium-паки. Исходные PDF и промежуточные тексты намеренно
не являются частью итоговой поставки.

## Сборка и релизы на GitHub

Workflow `.github/workflows/build-release.yml` запускает `npm ci`, тесты, проверки и `npm run build` при push и pull
request. Его также можно запустить вручную через Actions. Артефакт `shinobi-vtt` содержит установочный `shinobi-vtt.zip`
и `system.json`.

Сборка использует готовые паки из `packs/catalog`, `packs/tables` и `packs/vehicles`, поэтому их актуальные файлы должны
быть в Git. Пересборка паков из локальных исходников в CI не выполняется. Папку `tests/` также нужно коммитить.

Для релиза обновите версию в `system.json` и `package.json` (вместе с `package-lock.json`), закоммитьте изменения и
отправьте соответствующий тег:

```sh
git tag 1.0.0
git push origin 1.0.0
```

Тег указывается без префикса `v` и должен точно совпадать с версией в `system.json`. После успешной сборки workflow
публикует GitHub Release с архивом и манифестом; теги с дефисом, например `1.1.0-beta.1`, публикуются как prerelease.
Ссылки в релизном манифесте формируются автоматически для текущего репозитория. Для установки в Foundry используйте
ссылку на `system.json` из релиза; стабильная ссылка имеет вид
`https://github.com/OWNER/REPO/releases/latest/download/system.json`.

Публикация использует встроенный `GITHUB_TOKEN` с правом `contents: write` только в задании релиза; отдельный токен не
нужен.
